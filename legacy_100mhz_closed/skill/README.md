# 技能包与协作方法

本项目沉淀以下可复用方法：

- 采用模型配置和参数文件双重核对模型几何、共享权重和量化尺寸。
- 仿真、综合、上板和性能数据分别保持独立口径。
- PS 裸机程序按 AXI-Lite 寄存器顺序配置 PL，并通过状态寄存器等待完成。
- KV260 使用 SD 自动启动，串口交互采用 115200 8N1。
- 性能分析使用板内 ticks，并明确首输出与 decode 阶段。
- 测试数据以原始日志、CSV、JSON 和 SHA-256 形成可追溯证据链。

项目资料按 `src / sim / build / board / data / report` 分类，源码与结果保持可复现。
